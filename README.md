# Quizzical 🧠

A dynamic, customizable quiz application built with **React 19**. Test your knowledge across various categories, difficulties, and question types sourced from the Open Trivia Database.

## 🚀 Features

-   **Customizable Settings**: Filter quizzes by category (General Knowledge, Science, History, etc.), difficulty levels, and question types.
-   **Interactive UI**: Smooth transitions between the home settings and the quiz interface.
-   **Instant Feedback**: Highlighting correct and incorrect answers clicking upon check answers button.
-   **Celebratory Finish**: Uses `react-confetti` to celebrate perfect scores.
-   **Responsive Design**: Fully optimized for mobile, tablet, and desktop views.

##  🛠️ Tech Stack

-   **Language:** JavaScript, HTML5, CSS3
-   **API:** Open Trivia DB API
-   **Framework/Library:** React
-   **Oher Libraries**:
    -   `html-entities` for decoding API strings.
    -   `react-confetti` for the win animation.

## Getting Started

Install the dependencies and run the project

```
npm install
npm start
```
